# Halp of BD

A crypto-powered utility app built on the **Celo** blockchain, enabling users in Bangladesh to pay for everyday digital services with cryptocurrency.

## Features

- **Wallet Connect** — Connect via MetaMask, MiniPay, or any WalletConnect-compatible wallet
- **Mobile Recharge** — Pay with supported tokens to recharge Bangladeshi mobile numbers
- **Multi-Operator Support** — Supports Grameenphone, Robi, Banglalink, Airtel, and Teletalk
- **Data & Drive Packs** — Browse operator internet packages
- **Bill Payments** — Pay electricity, gas, and utility bills
- **Gaming Top-Ups** — Buy Free Fire diamonds and other digital top-ups

## Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS, Vite
- **Blockchain:** Celo Network (EVM-compatible)
- **Wallet Integration:** WalletConnect v2, ethers.js
- **Backend:** Lovable Cloud (database, edge functions, authentication)

## How It Works

1. Connect your crypto wallet
2. Choose a service and enter the required details
3. Pay with a supported token
4. Receive service confirmation in the app
